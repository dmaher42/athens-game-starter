# Game Hotkeys

This document outlines the keyboard controls for the game.

## Movement

| Action  | Key(s) |
|---|---|
| Forward | W |
| Back | S |
| Left | A |
| Right | D |

## Looking

| Action | Key(s) |
|---|---|
| Look Left | ArrowLeft, Q, Comma, J |
| Look Right | ArrowRight, E, Period, L |
| Look Up | ArrowUp, R, I |
| Look Down | ArrowDown, X, K |

## Actions

| Action | Key(s) |
|---|---|
| Jump / Fly Up | Space |
| Sprint | Left Shift, Right Shift |
| Toggle Fly | G |
| Crouch / Fly Down | Left Control, Right Control, C |
| Interact | F |
